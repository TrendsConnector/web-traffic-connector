## How to ask

No website name. Pass a category such as finance. A subcategory uses the parent/child form, such as finance/investing.

**Good to know:** This is the ranked list for that category. It does not return a visit history for one domain, and it does not show which pages people opened.

## FAQ

**Can I track one website?**  
No. You name a category, such as finance, and get the sites ranked in that category.

**Can I use a subcategory?**  
Yes. Use the parent/child form, such as finance/investing.

**Is the Web Traffic connector free?**  
Yes. The free plan has 100 requests a month and includes every source. No credit card. Paid plans start at $19 a month for 1,000 requests.

**Which AI apps work with it?**  
Claude, ChatGPT, Cursor, VS Code, Claude Code, Grok, Muse, Perplexity, Gemini, Copilot, Windsurf and any app that supports MCP connectors.
